# Service card photography

Placeholder photography for the service cards in `DivisionsShowcase`, one file
per division slug in `src/data/divisions.js`.

All files below are from Unsplash and are used under the [Unsplash License]
(https://unsplash.com/license), which permits free commercial use without
permission. Attribution is not required, but is recorded here so each
photographer can be credited or the source traced.

## Replacing these with the firm's own photos

Drop a landscape JPG (1400x875, or any 16:10 crop) over the file of the same
name - nothing in the code needs to change. To point at a different filename,
edit that division's `image` field in `src/data/divisions.js`. If a file is
missing, the card falls back to its gradient icon panel instead of breaking.
